# Security Policy

## Supported versions

Only the default branch is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| other   | :x:                |

## Reporting a vulnerability

Please report security issues **privately**. Do not open a public GitHub issue
for vulnerabilities.

Preferred channel:

1. **GitHub Security Advisories** — use *Security → Report a vulnerability*
   (private vulnerability reporting) on this repository. That is the
   `security@` path for this project.

Include enough detail to reproduce the issue (affected version or commit,
environment, and steps). We will acknowledge the report, work on a fix, and
coordinate disclosure before any public discussion.
